Barcode Types and Formats

Each format was designed for a particular job, and some of them accept only digits. These are the ones people use most.

Code 128

Code 128 accepts letters, numbers and symbols, and it produces short barcodes. When the data is all digits, it stores them in pairs, which keeps the barcode small. Warehouses, shipping companies and inventory systems use it more than any other format.

It has three subsets: 128A for uppercase letters and control characters, 128B for upper and lower case, and 128C for digits only. The generator picks the right one for your data, and you can choose a subset yourself if a scanner or a client asks for it. GS1-128 is a related format that holds extra details such as batch numbers and expiry dates. It is common in logistics and healthcare.

Code 39

Code 39 takes uppercase letters, digits and a few symbols. It is older than Code 128 and needs more space, but nearly every scanner can read it. You will see it on ID badges, equipment tags and in automotive and defense paperwork.

EAN-13 and EAN-8

EAN-13 is the retail barcode used in most countries outside North America. It has 13 digits, and the last one is a check digit that the tool works out for you. EAN-8 is a shorter version for small packages.

UPC-A and UPC-E

UPC-A has 12 digits and is the standard retail barcode in the United States and Canada. UPC-E is a shortened form for small products.

2D Barcodes

Two-dimensional codes hold more data in a small square. Data Matrix is used on small parts and electronics, PDF417 on boarding passes and driver licenses, and Aztec Code on tickets. QR codes are the best known type and suit links and short text.

Other Formats

ITF-14 is printed on shipping cartons. Codabar is still used in libraries and blood banks, and Pharmacode on medicine packaging. ISBN, ISMN and ISSN are for books, sheet music and periodicals.

Which Barcode Format Should You Use?

  • Retail products: EAN-13 in most countries, UPC-A in the US and Canada.
  • Inventory and internal stock: Code 128.
  • Parcels and pallets: Code 128 or GS1-128. Outer cartons: ITF-14.
  • Asset tags and badges: Code 39 or Code 128.
  • Small parts and electronics: Data Matrix.
  • Books and magazines: ISBN or ISSN.

If a customer, marketplace or warehouse gives you requirements, follow those first.

One thing sellers often miss: the tool makes a valid barcode image from whatever number you enter, but it doesn't give you ownership of that number. To sell in stores or on large marketplaces, EAN and UPC numbers usually have to be licensed through GS1. For tracking your own stock, any numbers will do.

Barcode Size, Quality and Printing Tips

A barcode that looks fine on screen can still fail at the checkout. These habits prevent most problems.

  • Use dark bars on a white background. Light colors, patterns and glossy surfaces cause misreads.
  • Leave blank space on both sides of the barcode, called the quiet zone. Text or graphics too close to the edges can stop it from scanning.
  • Scale it evenly. Stretching the width or height changes the bar proportions and breaks the code.
  • Don't print too small. A standard EAN-13 is about 37 mm wide at full size and shouldn't go below 80 percent of that.
  • Use SVG for large prints. Use PNG when placing the barcode in a document or label template.
  • Print one first and scan it with the device you will actually use, then print the rest.

Frequently Asked Questions

What is the difference between Code 128 and Code 39?

Code 128 is more compact and accepts the full ASCII set, including lowercase letters. Code 39 handles only uppercase letters, digits and a few symbols, and it needs more space for the same data. Use Code 128 unless someone specifically asks for Code 39.

Can I make many barcodes at once?

Yes. Enter one value per line, or paste a column from Excel or a CSV file, and the generator makes a barcode for each line. Multiple barcodes download together as a ZIP file.

Do I need to buy numbers to use EAN or UPC barcodes?

For retail sales in stores and on major marketplaces, yes. The numbers are normally licensed through GS1. For internal use, like tracking stock inside your own business, you can use your own numbers.

Which file format is best for printing?

SVG, because it can be enlarged without losing sharpness. PNG works well when you place the barcode in a document or label design at a fixed size.

Which barcode type is best for inventory?

Code 128. It is compact, accepts letters and numbers, and nearly all scanners support it.

Can I use the generator on my phone?

Yes. The tool runs in the browser, so it works on phones, tablets and computers.
